Review Cockpit

A faster, keyboard-first review experience on top of GitHub.

1. Connect GitHub

Review Cockpit uses the GitHub API to read pull requests and sync GitHub's own Viewed checkboxes. Your token is stored only in this browser (chrome.storage.local) and is only ever sent to api.github.com.

  • Quickest: create a classic token with the repo scope.
  • Least privilege: create a fine-grained token with Pull requests: Read and write and Contents: Read on the repos you review.
  • If your org uses SAML SSO, click Configure SSO → Authorize next to the token afterwards.

2. Review faster

Open any pull request on github.com. The panel appears on the right.

Alt + J / KNext / previous file
Alt + NJump to the next unviewed file
Alt + VToggle Viewed on the current file (syncs with GitHub)
Alt + /Filter files
Alt + RShow / hide the panel

On macOS, Alt is the ⌥ Option key.
